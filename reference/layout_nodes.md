# Node table of a layout

Node table of a layout

## Usage

``` r
layout_nodes(x)

layout_links(x)

layout_sectors(x)

layout_tracks(x)

layout_params(x)
```

## Arguments

- x:

  A `circos_layout`, or a `circos_layouts` list (the `by =` result), in
  which case a named list of the per-panel tables is returned.

## Value

A data frame; see
[`circos_layout()`](https://yulab-smu.github.io/ggcircos/reference/circos_layout.md)
for the column contract.
